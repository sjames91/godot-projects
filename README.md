# Godot Projects

Projects made with [Godot](https://godotengine.org).

- **[Tessera](tessera)** is a layered, cell-based pixel art editor in Godot 4 (GDScript + shaders). Every mark is a cell, every layer is a way of rendering cells, and layers with different tilings stack on top of each other.
